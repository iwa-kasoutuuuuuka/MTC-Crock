80年代前半の国産クラシックミニバイク（HONDA モトコンポ NC50等）のスピードメーターをモチーフにした、常時点灯対応のAndroid置き時計アプリケーションです。  
引き出しで眠っているスマートフォンやタブレットを、デスクやベッドサイドを彩る高品質なレトロ・インテリア置き時計として美しく蘇らせます。

## 🌟 デザインのこだわり & 再現仕様

### 1. 🏍️ レトロ＆メタリック・スピードメーターデザイン
- **国産クラシックバイクのメーター造形を極限まで追求**
  - **マットブラック角丸樹脂ベゼル**: 重厚なスクエア樹脂ボディと内周への立体ベベル傾斜を再現。
  - **完全正方形エメラルドグリーングリッド**: 80年代モトコンポ特有の格子パターン（縦5本×横5本、各辺6等分）。中心十字線が針の回転軸および12時・6時・9時・3時と完全一致。
  - **外周 1〜12 時表示**: 1〜8時はホワイト太字 / **9〜12時は鮮烈なレッド太字**（太く力強いボールドサンセリフ書体）。
  - **9時〜12時 速度警告赤帯（90度扇形アーチ）**:
    - 数字「9」「10」「11」「12」と**一切重ならない独立した幾何学設計**。
    - 9時側は水平カット、12時側は中央縦線に沿って垂直カット。
    - 数字と赤帯の間に黒い空間と緑のグリッド線が美しく通る絶妙な配置。
  - **マスタードイエロー 3D アナログ針 & センターハブ**:
    - 針の中央稜線（リッジ）によるハイライトとシャドウ（山型3D断面）。
    - センター丸型ハブキャップの背後・斜め下左右に突き出る**二股爪状ウィングパーツ**を忠実に再現。
  - **固定ボルト（2本）**:
    - 下から2本目（中央線から1マス下）の水平グリッド線上に左右対称配置。
    - 金属感のあるリアルなグラデーションと立体的なプラス頭十字スリット。

- **トリップメーター風 デジタル液晶表示部 (LCD小窓)**
  - ベゼル最下部にインセット成型されたレトロTN液晶（オリーブセピア色基板）。
  - **左ブロック**: 月（英語3文字 `OCT` 等）、日（2桁 `26` 等）、`AM/PM`。
  - **中央ブロック**: 肉太7セグメントデジタル時刻（薄い消灯ゴースト `88:88` 付き）。
  - **右ブロック**: 英語天気コンディション＋気温（例: `Sunny, 72°F`）および **ベクター液晶バッテリーアイコン＋残量%**。

## ⚡ 主な機能一覧

| 機能分類 | 機能概要 | 詳細仕様 |
| :--- | :--- | :--- |
| **描画性能** | 60fps スムーズ運針 | Jetpack Compose Canvas による超低負荷・高フレームレート描画。 |
| **画面制御** | 全画面常時点灯 | `FLAG_KEEP_SCREEN_ON` によるスリープ防止、Immersive Mode によるナビバー/ステータスバー完全非表示。横画面（Landscape）固定。 |
| **パネル保護** | 有機EL焼き付き防止 | 5分ごとに時計全体の描画座標をランダムピクセルシフト。定期的な色調微調整および夜間自動減光。 |
| **時刻精度** | NTP自動時刻同期 | Wi-Fi接続時に NTPサーバー (`pool.ntp.org`) と自動通信し、ミリ秒単位で内部時計を正確に補正。 |
| **気象情報** | リアルタイム天気 | Open-Meteo REST API（登録不要・無料）より最新の天気・気温・湿度・降水確率・風速を取得。オフライン時は自動キャッシュ。 |
| **電源管理** | バッテリー & 温度監視 | バッテリー残量(%)、充電ステータス、端末内蔵バッテリー温度を表示。 |
| **カスタマイズ**| テーマ & 表示設定 | 温度単位切替（`°C` / `°F`）、各種要素の表示ON/OFF、3種類のカラーテーマ（`SPORT`, `RACING`, `CLASSIC`）、昼夜自動輝度切替。 |

## 👆 フル画面マルチジェスチャー操作

画面上のどこからでも直感的なタッチ操作で各機能へ素早くアクセスできます。

```
       [ 上スワイプ: 画面を明るく ]
                   ▲
[ 右スワイプ: 設定 ] ◀ [ 画面中央 ] ▶ [ 左スワイプ: 天気詳細 ]
                   ▼
       [ 下スワイプ: 画面を暗く ]
```

- **👉 右スワイプ**: 各種設定画面を表示（温度単位、昼夜輝度、テーマ等）
- **👈 左スワイプ**: 詳細天気予報画面を表示（週間予報、湿度、風速等）
- **👆 上下スワイプ**: 画面の明るさを手動調整（0〜100%のインジケーターを一時表示）
- **⏱️ 長押し**: クイックメニューダイアログを表示
- **⚡ ダブルタップ**: 設定や天気画面からいつでも直ちに時計画面へ復帰

## 💡 古いスマートフォンを置き時計として活用するコツ

1. **常時給電とバッテリー保護**
   - 本アプリはバッテリー残量および温度をリアルタイムで監視しています。
   - 長期間の常時点灯運用時は、過熱を防ぐため直射日光を避けた風通しの良い場所に設置してください。
2. **夜間の眩しさ防止**
   - 設定画面の「昼夜自動明るさ制御」を使用することで、夜間（デフォルト 19:00〜07:00）は自動的に画面輝度を落とし、睡眠を妨げません。
3. **有機EL端末での安心運用**
   - OLED端末特有の画面焼き付きを防ぐため、バックグラウンドで数ピクセル単位の微細シフトが常時動作しています。

## 🚀 ビルド & 開発手順

Android Studio または Gradle CLI を使用してすぐにビルド・テストが可能です。

### 前提条件
- JDK 17 以上
- Android SDK (API Level 36, Build-Tools 36.0.0)

### コマンド一覧

```powershell
# リポジトリのクローン
git clone https://github.com/iwa-kasoutuuuuuka/MTC-Crock.git
cd MTC-Crock

# ユニットテストの実行
.\gradlew.bat test

# デバッグAPKのビルド (app/build/outputs/apk/debug/app-debug.apk)
.\gradlew.bat assembleDebug

# 接続端末 / エミュレータへの直接インストール
.\gradlew.bat installDebug
```

## 📝 更新履歴 (Changelog)

### v1.0.0 (Design & Geometry Overhaul)
- **速度警告赤帯の完全幾何学分離**: 9時〜12時の90度扇形アーチを数字（9〜12）と一切重ならない独立した内周配置に刷新。
- **完全正方形グリッドの採用**: 縦5本×横5本（各辺6等分）のグリッドを構築し、中心交点とハブ軸を完全一致。
- **メーター針 & センターハブの立体造形**: マスタードイエロー山型針に中央稜線を追加し、ハブキャップ背後の斜め下二股爪状ウィングパーツを再現。
- **固定ボルトのリアル質感向上**: 下から2本目のグリッド線上に左右対称配置し、金属グラデーションと十字プラススリットを強調。
- **LCD小窓のモダンレトロ化**: 英語表記月名・日、AM/PM、7セグメント時計（消灯ゴースト付き）、英語天気名＋気温、ベクター液晶バッテリーアイコンを実装。
- **テストスイートの健全化**: 温度変換・フォーマットロジックのユニットテストを整備。
